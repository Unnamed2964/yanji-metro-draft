## 规范

本项目所生成的所有线路图，都在架空世界观中被假设为在中华人民共和国境内的公共场合，尤其是面向延边的汉族、朝鲜族在内的各族群体张贴、分发和使用。

- 英文站名应采用中华人民共和国/朝鲜/韩国国内惯例（除中华人民共和国相关法律或规定有特殊要求外）

  | 地名 | 本项目采用 | 常见非采用形式 | 备注                                                         |
  | ---- | ---------- | -------------- | ------------------------------------------------------------ |
  | 平壤 | P'yŏngyang | Pyeongyang     | 朝鲜采用马科恩-赖肖尔表记法进行转写，参见维基百科            |
  | 首尔 | Seoul      | Sŏul           | 韩国采用文化观光部2000年式表记法进行转写，参见维基百科       |
  | 延吉 | Yanji      | Yŏngil/Yeongil   | 中国国铁车站名中的地名专名部分一般采用汉语拼音<br />参考呼和浩特地铁[^1]的惯例，地铁车站名中的没有固定翻译惯例的少数民族语言专名部分一般也采用汉语拼音 |

- 中国境内站名中的地名/专名的朝语翻译应采用中国朝鲜语报纸/广播/出版等采用的惯例
  
  朝鲜/韩国境内，除中华人民共和国相关法律或规定有特殊要求（如涉及长白山的特殊地图要求）外，应采用朝鲜/韩国当地惯例

  中国境内地名按下列顺序处理：
  1. 先查**中国朝鲜语**报纸、广播、出版等是否已有惯用写法，有则采用
  2. 无定译时再看语源：近现代从满语等少数民族语言音译得出的地名，采用音译（如哈尔滨 → 할빈），不用汉字音
  3. 一般汉语地名采用汉字音，且不采用头音法则（如沈阳 → 심양，洛阳 → 락양）
  4. 朝鲜族聚居区局部地名可能与汉字音不完全对应，以官方或地方公开资料为准（如头道 → 투도，这来自于当地公路指向的双语标注）

  中国境内专名（机构名等）及外国地名的朝语翻译参照上列顺序处理，尤以第1条惯用写法为准，不适用第4条。
  
  | 地名/专名 | 本项目采用 | 常见非采用形式 | 备注                                                         |
  | ------ | ------ | ------ | ------------------------------------------------------------ |
  | 龙井   | 룡정   | 용정   | 不采用头音法则                                               |
  | 哈尔滨 | 할빈   | 하얼빈 | 见上第1、2条 |
  | 沈阳   | 심양   | 선양   | 见上第1、3条 |
  | 深圳 | 심수 | 선전/심전/심천 | 见上第1条 |
  | 俄罗斯 | 로씨야 | 러시아 | 外国国名采用中国朝鲜语惯例                                   |
  | 头道   | 투도   | 두도   | 见上第4条 |
  | 延边广播电视台 | 연변라지오TV방송국 | 연변라디오TV방송국 | 见上第1条；中国朝鲜语对 radio 用 라지오，不用 라디오 |
